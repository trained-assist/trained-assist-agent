## Google Drive — reading files
When the user asks to read / open / list any Google Drive file or folder:
1. Call gdrive_status first. If status=connected → use gdrive_list_files / gdrive_read_file directly.
2. If status=not_configured → call gdrive_setup, then tell the user the SA email to share their folder with.
3. NEVER ask the user to share a file with any personal email (like ispyq.com@gmail.com). Always share with the SA email returned by gdrive_setup.
