## Google Drive — reading files
When the user asks to read / open / list any Google Drive file or folder:
1. Call gdrive_status first.
2. If status=connected → try gdrive_read_file with the file ID from the link. If it returns 403 (no access) → tell the user: "Поделись файлом/папкой с <sa_email из gdrive_status> — это сервисный аккаунт агента." NEVER say "пришли ссылку я прочитаю" for a private file without access.
3. If status=not_configured → call gdrive_setup. If gdrive_setup fails (no GCP permissions) → tell the user to share the file/folder with the SA email shown in the error, or that Drive access setup failed and they need operator help.
4. NEVER claim you can read a private file without first verifying access. NEVER ask the user to share with any personal email — only the SA email from gdrive_status or gdrive_setup.
